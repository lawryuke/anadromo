# Reglas del Proyecto Anádromo

## Flujo de Trabajo y Gestión de Issues
- **Autorización Estricta:** NUNCA te adelantes a escribir código, modificar archivos o resolver "Issues" del tablero sin la autorización previa y explícita del usuario.
- Si el usuario te pide listar el estado actual o los siguientes pasos, limítate a informar y sugerir. Espera la confirmación antes de ejecutar la implementación de un Issue.
